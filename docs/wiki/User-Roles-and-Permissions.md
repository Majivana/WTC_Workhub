# User Roles and Permissions

System roles are separate from work roles.

System roles:

- Student
- Mentor
- Supervisor
- Admin
- Super Admin

Work roles are configurable, for example Peer Tutor, Front Desk Assistant, IT Support,
Marketing Assistant, Wellness Coordinator, Recruitment Ambassador, and Placement Facilitator.

Authorization is enforced server-side using permissions, ownership, and supervisor assignment.
