# WTC Workhub

WTC Workhub is a proposed student workforce, work evidence, attendance, and supervisor
verification platform.

The MVP golden path is:

```text
Student sign-in
-> campus-validated selfie clock-in
-> work and activity recording
-> evidence upload
-> submission
-> supervisor review
-> immutable verification
-> notification and progress update
```

This Wiki source is based on supplied current-system evidence and explicitly labels proposed
redesign decisions.
