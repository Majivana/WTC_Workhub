# API Documentation

The API contract is not implemented yet. Planned resource groups are:

- `/auth`
- `/users`
- `/campuses`
- `/work-periods`
- `/attendance-sessions`
- `/work-entries`
- `/evidence`
- `/submissions`
- `/verifications`
- `/notifications`
- `/escalations`
- `/reports`

Each endpoint must document authentication, authorization, validation errors, response shape,
and audit behaviour before it is marked complete.
