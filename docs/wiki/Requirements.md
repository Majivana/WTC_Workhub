# Requirements

## Functional

- Authenticate users and enforce RBAC.
- Configure institutions, campuses, work roles, activities, and WorkPeriods.
- Capture clock-in/out sessions with selfie and campus-location evidence.
- Record work entries and activities.
- Upload private evidence with versioning.
- Submit, review, approve, reject, or request changes.
- Preserve verification and audit history.
- Reconcile attendance sessions with work and evidence.
- Provide dashboards, notifications, escalations, and CSV reporting.

## Non-functional

- Secure by default.
- Testable domain rules.
- Portable relational persistence.
- Observable deployed services.
- Explicit error handling.
- No unsupported claims about AWS or external integrations.
